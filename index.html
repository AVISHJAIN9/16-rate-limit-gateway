System Design

F1: Multi-Algorithm Engine

Supports Token Bucket, Leaky Bucket, Fixed Window, Sliding Window Log, and Sliding Window Counter.

F2: Atomic Redis Lua Scripts

Executes quota evaluations atomically inside Redis, eliminating distributed race conditions and double-bursts.

F3: Client Identity & Scopes

Prioritized client extraction from JWT claims, API keys, and CIDR subnet masking with dynamic route cost resolvers.

F4: Dynamic Policy Engine

Runtime policy hot-reloading from YAML and JSON without requiring gateway process restarts.

F5: Real-time Web Console

React 19 admin dashboard displaying real-time quota consumption and worker health.

High-Scale Systems Architecture

Capacity estimation and resilience modeling for 100,000 requests/second with sub-millisecond overhead.
